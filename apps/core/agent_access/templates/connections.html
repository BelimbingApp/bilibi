  • Claude Code. Run claude mcp add --transport http {{ server_name }} {{ address }}. Then start Claude Code, type /mcp, choose {{ server_name }} and sign in.

Only programs on this computer can reach this Bilibi. Here is what works.

  • Claude Code and Codex on this computer connect directly. Use the steps above.
  • A Node-based tool, such as Claude Code, says the certificate is not trusted. This happens when it runs in WSL. Run export NODE_EXTRA_CA_CERTS="$(mkcert -CAROOT)/rootCA.pem", add the same line to your shell start-up file (~/.bashrc), and start the tool again.
  • Desktop and web apps with connectors that run in the app maker's cloud, such as claude.ai and the connector screens in the Codex desktop app, cannot reach a .localhost address. Give them a public tunnel address to this Bilibi, or use a Bilibi that is deployed on the internet.
