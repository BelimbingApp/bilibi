Inline facts

Read-first facts: the stored value is the trigger. Nothing is painted until the owner replies; the fact reads "Saving…" for its own round trip, then reports the outcome on itself. This page has no live socket, so it shows the read and outcome states; /inline-reference in the u5-inline example runs the lifecycle.
