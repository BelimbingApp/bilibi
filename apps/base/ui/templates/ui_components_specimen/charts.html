Charts

One server-rendered SVG figure (Chart): a KPI number, bars side by side or stacked, lines, a pie and a donut, in the data colours cat-1 to cat-8, never status colours. Every mark has a title, the figure is described for screen readers, and the Data fold holds the exact values. A gap stays a gap. With no data, or more than it can draw honestly, the chart says so and keeps the data.
