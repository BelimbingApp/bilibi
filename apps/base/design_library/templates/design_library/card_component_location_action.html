A location action asks the browser for its position when clicked, then raises its event with the latitude, longitude and accuracy, or with why there is none. The browser asks for permission on the first click; a refusal, an unavailable position and an insecure (http, off localhost) connection each reach the page as an outcome it answers in words. The page keeps only the last report, in this page's memory.
