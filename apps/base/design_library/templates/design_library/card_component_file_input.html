The live file input streams each chosen file to the page over its socket in 64 KiB chunks and lists it with its progress and a Remove action. The server holds the rules and every byte: a file over the limit or of a kind the input does not accept is refused before anything is sent, and the page receives the bytes only in the event that acts on them, here Keep files.

A resumable input keeps its chunks in a private staging file on the server instead of the page, so a dropped connection, or a server restart, carries on from the bytes already there. The browser announces the file's SHA-256 first, and the page receives the bytes only once they match it.
