Accepted choices

These are the current rules for Bilibi.

Application shell

Account details belong behind the bottom-left circle, including the Platform-operator caution row when the tenant is the platform operator; only impersonation, which has an exit, stays above the workspace. Where a screen's own reach is not filtered to one company, that screen says so in the same caution colour: the SQL console warns beside the query it runs, and an authorization listing the operator scope widens to rows attached to no company carries a one-line caption above its table, and the roles list, whose Principals counts it widens, names those counts. An account works in one company and tenant, so the menu shows the current scope and offers no switching.

The clock selects Company, Local or UTC time. Sun, moon and desktop select Light, Dark or System theme. A saved choice confirms in place, updates the controls and follows your account; every timestamp already rendered through <.datetime> changes with it, without a reload and without losing your place, and every screen you open afterwards uses the new choice. A screen that formats instants directly rather than through that component is unaffected until it adopts it. While saving, controls prevent duplicate work; a failed save keeps the previous choice and explains how to retry. While you view as another user, the top bar reports the active time display and offers no controls, because those preferences belong to the account you are viewing.

Menus close on Escape or outside click and return keyboard focus to their trigger on Escape. The narrow drawer contains keyboard focus and returns it to the sidebar toggle when closed.
