## Product fix

An uploaded release's review headline read “Install release 1 from” because the page handled only sibling and HTTPS sources.

The page now uses the operation's existing summary. On the corrected running program, the first review line was “Production: install release 1 from the release file upload-1 uploaded here (from Dev)”. The browser assertion checked that line at the exact Production origin with an empty code field. No second source formatter or public API was added.

The operator docs now put both builds on the operator's own machine and copy the finished installer to the server. They also state the observed local-folder limitation: no `release.json`, so an upload review warns that its change list is known only once the installer reads the program. Job 1 then recorded Finance's exact pinned composition and the added Domain.
